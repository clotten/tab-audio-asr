自测页

这个页面不依赖任何外部网站，用来验证「捕获 → 编码 → 上传 → 识别」这条链路。建议顺序：先测音调，再测语音。

1. 音调测试（验证抓取和上传链路）

播放 10 秒 1kHz 音调。它一定能被标签页音频捕获，用来确认插件能拿到声音、能编码、能调通接口。 纯音调**本来就不该识别出文字**，只要插件显示「接口 200 / 已转写 1 段」且没有报错，链路就是通的。

2. 语音测试（验证识别效果）

用浏览器自带的语音合成朗读一段中文。注意：部分浏览器把语音合成的音频走在单独的通道上， 可能不被标签页捕获；如果这里识别不出文字，但音调测试正常，请改用真实视频测试。

3. 真实场景

  1. 打开任意在线视频（B 站 / YouTube / 播客网页 / 网课平台），确保能听到声音。
  2. 点插件图标 → 「开始转录」，第一次需要填 API Key。
  3. 等第一个分段（默认 20 秒，可在设置里改小到 10 秒，更快看到结果）；页面底部会同时出现悬浮字幕层。
  4. 文字稿会边录边出现；停止后还能继续导出 TXT / SRT。

小技巧：先播着视频再点开始，避免开头几句被截断。录的时候**不要切到别的标签页把声音静音**—— 标签页自己静音了，捕获到的也是静音。
