# 网页音频 → 文字（Edge / Chrome 扩展）

把网页里正在播放（或可下载）的视频声音，转成可搜索、可导出、可双语的文字稿。

> 面向的场景：看网课 / 讲座 / 外语视频，想要一份能回看、能检索、能记笔记的字幕，
> 而不是"错过一句就倒回去重听"。

## 它能做什么

| 能力 | 说明 |
|---|---|
| **整段提取** | 直接取整条音轨转写，不用等播放。8 分钟的视频约 26 秒出全稿 |
| **实时转录** | 边播边出字，任何能出声的页面都能用 |
| **双语字幕** | 识别用一种接口、翻译用另一种接口（默认可接 DeepSeek），生成原文 + 译文 |
| **悬浮字幕面板** | 贴在视频上，按视频时间轴高亮当前句，可拖动缩放 |
| **字幕库** | 按视频自动存档，同一视频再打开自动命中，不重复花钱 |
| **导出** | TXT / SRT / 复制；有译文时导出双语 |

## 安装

1. 下载本仓库（Code → Download ZIP）并解压
2. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）
3. 打开右上角「开发人员模式」
4. 点「加载解压缩的扩展」，选中解压出来的文件夹
5. 点工具栏上的插件图标 → 「设置」标签 → 填自己的 API Key

> 识别调用硅基流动的 ASR 接口（`Qwen/Qwen3-ASR-1.7B`），按用量计费，用自己的额度。
> 翻译可另填一套（任意兼容 `/chat/completions` 的服务）。

## 两种用法

```
整段提取（不用等播放）
  ├─ B 站：直接可用（读 BV 号 → cid → 播放接口 → 音轨）
  └─ 其它站点：网址是直链 mp4 就行；MSE/blob: 的站点走实时转录

实时转录（跟着播放走）
  └─ 任何能出声的页面；字幕延迟约 12 秒（默认准确率优先）
```

界面上三个页签：

- **转录**：整段提取 / 实时转录 / 字幕库 / 字幕正文
- **字幕库**：按视频存的历史稿，可加载或删除
- **设置**：接口、模型、术语表、翻译接口、各项开关

## 已知边界

- **不支持**：Netflix 等 DRM 保护的站点；纯 blob: 且没有可读播放接口的站点无法整段提取
- **实时延迟**：默认 12 秒一批（准确率优先）；想低延迟可把 `lib/vad.js` 里的
  `softCutMs / hardCutMs` 调回 6000 / 10000
- **长音频**：整段提取单文件上限 45 分钟 / 600MB
- **准确率**：取决于云端模型；专有名词建议填术语表

## 隐私

- **API Key 只存在你自己的浏览器里**（`chrome.storage.local`），不上传、不写进代码
- 音频会上传到你自己配置的接口服务商（默认 siliconflow.cn）用于识别
- 除此之外不收集任何数据：没有统计、没有遥测、没有远程配置
- 仓库里不含任何密钥；`.gitignore` 已排除本地密钥文件

## 开发

```bash
node tools/build-dist.mjs   # 打包到 dist/（可直接加载的目录）
node tools/smoke.mjs        # 冒烟测试：包能不能被浏览器接受
```

19 个测试/检查脚本，分三层（静态检查 / 单元测试 / 跨上下文仿真），清单见 `tools/`。

```
manifest.json  background.js  offscreen.*  popup.*     ← 扩展本体
content/   注入到网页的脚本（媒体探针、字幕面板）
lib/       纯逻辑模块（VAD、增量提交、翻译、字幕库…），都有单测
vendor/    onnxruntime-web + Silero VAD 模型（离线语音判别）
tools/     测试、构建、对比脚本
docs/      开发笔记、开发文档、复盘、待修清单
demo/      自测页（不用真实网站就能验证播放/识别链路）
```
